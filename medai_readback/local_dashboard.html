    Call budget
    —
    The working limit lives in this workspace’s database and applies immediately, with no restart. CALLE_CALL_BUDGET in .env is the hard ceiling: the dashboard can lower the working limit, never raise it past that. Reserved calls are never released, so lowering the limit below the reserved count simply leaves nothing available.
    Saving never places a call.
    Automatic reminder calls
    —
    Due reminders are dialled by a separate worker process, inside the same budget and phone allowlist as manual calls. Confirmation calls are never dialled automatically — they read prescription details aloud to a patient, so a person releases each one.
    python worker.py --once          # list due reminders, dials nothing
python worker.py --live          # dial due reminders every 30 seconds
    The worker reports in every 30 seconds. After 90 seconds of silence this dashboard treats it as stopped.
    Environment
    Read-only. Keys, tokens and phone numbers are never sent to the browser. Everything here comes from .env and needs a server restart to change.
